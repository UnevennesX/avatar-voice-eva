# Avatares de Voice-Eva

Este repositorio almacena los avatares de los usuarios de Voice-Eva.

## Estructura

```
avatars/
├── 1/
│   └── [timestamp].jpg
├── 2/
│   └── [timestamp].png
└── ...
```

Cada usuario tiene su propia carpeta identificada por su ID.

## Información

- **Generado automáticamente**: Este repositorio es gestionado por Voice-Eva
- **No editar manualmente**: Los archivos se suben/eliminan automáticamente
- **Público**: Las imágenes son accesibles públicamente para ser usadas en la aplicación
